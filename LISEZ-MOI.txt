ARENE MULTIVERS — BIBLIOTHEQUE ILLUSTREE V1

EXTENSION SEPAREE : NE PAS DEPLOYER SUR LE SITE NETLIFY DES FICHES V3.

1. Creer un NOUVEAU site Netlify Drop avec le dossier contenant index.html et manifest.json.
2. Copier l'URL du nouveau site et ajouter /manifest.json dans les extensions Owlbear.
3. Activer l'extension puis ouvrir son icone en haut a gauche.
4. Cliquer « Ajouter depuis Owlbear » pour choisir les images de tes assets Owlbear (personnages).
5. Les personnages apparaissent avec leur VRAIE image. Cliquer « Placer sur le plateau ».

La bibliotheque est sauvegardee dans le navigateur local. Exporter le JSON regulierement.
Les images restent dans Owlbear et les pions poses sont des pions CHARACTER normaux.
Le bouton « Image par URL » requiert un lien HTTPS direct avec CORS.
Cette V1 n'est pas une modification interne de l'extension Prefabs.
